ANALYTICAL MODEL

HBM is fast GPU memory. It holds weights, KV cache, and temporary work. The CPU coordinates serving; system RAM is a different memory pool. Not every GPU uses HBM.

These controls do not allocate GPU memory or alter Live lab timings. They are a separate, single-device dense-model calculator—not a hardware benchmark.
