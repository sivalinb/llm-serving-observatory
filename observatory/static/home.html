Why am I waiting?

Prefill processes the prompt. Decode generates the answer. TTFT measures the wait until the first visible output; total latency runs until completion.

The gateway’s clock and the visitor’s clock have different network boundaries.

02 / MEMORY
WeightsKV cacheWork
A memory budget · not to scale

What needs to fit?

Weights are the model’s learned parameters. The KV cache keeps attention state from earlier tokens. CPU models use host RAM; GPUs use device memory, which may be HBM or GDDR.

The Phoenix CPU profile has no GPU or HBM. GPU memory planning stays in the lab.

03 / EVIDENCE
Input + outputLatencyCPU / RAMTraces

How do I know?

Metrics show patterns. Traces connect request stages. Token counts come from the model server. Cached input and reasoning are subsets—not extra tokens to add twice.

Missing data stays unknown. “Extended tokens” is not a universal standard field.
