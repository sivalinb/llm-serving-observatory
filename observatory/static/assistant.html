02 / UNDERSTAND YOUR SPACE

A workspace is your view of the service.

Here, “workspace” means your signed-in account view: your daily allowance, the current question and answer, and your recent request metadata.

It does not create an OCI VM, a new cloud account, a private model or a ChatGPT workspace. People share the same small CPU model; the service checks ownership before returning personal history.

Questions and answers stay in this page’s memory. The database retains timing/token metadata and quota records—not a replayable chat transcript. Each question is independent; previous conversation is not sent as context.

03 / CHECK THE KEY, THEN THE PERMISSION

Authentication asks: “Who are you?”

When you connect, the browser sends your key in an Authorization: Bearer header. The gateway hashes it, finds an active matching key and identifies its account. It then returns that account’s allowance and history.

Authorization asks: “What may you see?” Personal requests are scoped to your account. Global dashboard data requires a separate operator grant. Protected API calls check the key again; dashboard permissions are checked on each privileged call.

Keys are held in page memory, not browser storage. Reconnect after reload or when opening the dashboard. Sign out clears the page; rotating a key invalidates the old one. Rotation does not remove an operator grant.

ILLUSTRATED AUTHENTICATION / NO REQUEST SENT

  1. BrowserBearer keyHeader, not a URL

On the OCI pilot, the localhost website travels through an approved SSH/Bastion tunnel. Its expiry breaks the connection—not your account. Never expose this HTTP port publicly.

04 / ASK A FOCUSED QUESTION

Ask about serving—not anything on the internet.

Use plain English and one specific question, between 3 and 800 characters. Good topics include TTFT, prefill/decode, token accounting, KV cache, CPU RAM, GPU/HBM concepts and this project’s operating limits.

This is a curated documentation assistant. It does not browse the web, upload files, inspect your OCI tenancy, execute commands, or read the dashboard on your behalf. It cannot diagnose live infrastructure just because you ask.

Examples below only fill the question box. You decide whether to search or ask the model. Avoid secrets, personal data and high-stakes questions.

05 / CHOOSE HOW TO LEARN

Search the evidence. Or ask for an explanation.

Search guides finds approved excerpts and source links. It requires your key but makes no model call and uses no generation tokens. Search remains available when AI is disabled.

Ask AI retrieves references, builds a prompt, checks the context budget and reserves quota/capacity. The CPU model reads the prompt (prefill), then streams generated text (decode). Input includes instructions and references, not just your question.

The shared OCI pilot caps answers at 64 output tokens, so ask narrowly. See the Service snapshot for this deployment’s configured limits. First answers can be slow on CPU. Stop cancels the stream; already-used or uncertain work is not refunded.

06 / INSPECT THE WORK

The receipt explains what happened.

TTFT is time to the first visible model content, measured by the gateway after authentication. It includes retrieval and waiting/prefill, but excludes browser/network time. Total time runs through terminal completion.

Input includes the prompt and references; output counts generated tokens. Cached input is part of input, and reasoning is part of output—not extra tokens to add again. Unreported values remain Unknown.

Open the retrieved sources and check the claims. Valid citation IDs are not proof of accuracy. A “length” finish reason means the answer hit its output cap. Check history before retrying an interrupted answer.

Total tokens = input + output. A trace ID is a correlation label; this shared deployment has no stored distributed trace to open.

07 / CONNECT THE OBSERVABILITY VIEW

Follow the question into the dashboard.

Open Observability, paste the same personal key and select Connect. It is a separate page-memory session. Viewing metrics makes no model calls.

Learners: use Requests and Events to inspect your own retained metadata. Search-only use creates no inference history. Select a request for its timing and token details.

Operators: Overview & alerts and Metric explorer also appear. Search for TTFT, memory, cache or tokens and choose a time window. In Requests or Events, choose All project and apply filters to see global metadata. An invitation alone does not grant this role.

If something looks wrong

Cannot open localhost? Your approved tunnel may have expired. Ask the operator to renew it; the OCI service can still be running.

Key rejected / 401? Use the personal key, not the invite or OCI password. A revoked key needs replacement access.

No global metrics / 403? A host-side operator grant is required. Ordinary learners should use their personal views.

AI unavailable / 503? Use Search guides. A configured model is not a guarantee of readiness; an operator must check it.
